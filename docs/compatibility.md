# Compatibility

What SafePatch runs on, and how each item was checked. "Tested" means an automated test in this repository
covers it; the test named is the one to rerun after a change.

## Platform

| | Status | Notes |
| --- | --- | --- |
| Windows 11 x64 | Tested (10.0.26200) | The worker needs AppContainer and Job Objects (`SafePatch.Sandbox.Tests`). |
| Windows 10 x64 | Expected to work | Same APIs; not in the test matrix yet. |
| Linux, macOS, Proton | Not supported | The sandbox is Windows-only. SafePatch refuses to run rather than run unsandboxed. |
| .NET runtime | 10.0 | Patchers are framework-dependent `net10.0`, as Synthesis's own template is. |
| AppContainer | Default | Zero capabilities; the container can read only the worker's own folder (ADR 002). |
| LPAC | Optional | `SandboxOptions.LessPrivileged`. Off by default: it needs an ACL grant on the .NET install. |

## Synthesis and Mutagen

| | Version | Notes |
| --- | --- | --- |
| Mutagen.Bethesda.Skyrim | 0.54.4, exact | Host and worker must read plugins identically (ADR 007). |
| Mutagen.Bethesda.Synthesis | 0.36.6, exact | The worker runs this `SynthesisPipeline`. |
| Synthesis app | Tested with the 0.36.6 CLI | `SafePatch.EndToEnd.Tests`, category `Synthesis`. The GUI runs patchers the same way but is not automated. |
| Output options | Tested | `--Localize`, `--SplitIfMaxMastersExceeded`, `--UseUtf8ForEmbeddedStrings` and `--TargetLanguage` (ADR 006, "Export options"). |
| Settings GUI | Tested with saved settings | Autogenerated settings reach the program (`Saved_settings_reach_the_sandboxed_program`). |

## Mod managers

| | Status | What to do |
| --- | --- | --- |
| None (plain Data folder) | Tested | Nothing. |
| Mod Organizer 2 2.5.2 | Tested (`Mo2LaunchTests`, run manually) | Add `SafePatch.Worker.exe` to MO2's executables blacklist (Settings > Workarounds). Let Synthesis build the patcher once outside MO2, because building under MO2 crashes the C# compiler (a known Synthesis issue). |
| Vortex | Not tested | Vortex deploys into the real Data folder, which SafePatch reads as it does without a manager. |

**Authoring against an MO2 profile** (`--mo2`) is tested with fake instances (`LoadOrderSourceTests`): SafePatch
reads `ModOrganizer.ini`, the profile's `modlist.txt` and `plugins.txt`, and layers the game's Data folder, the
enabled mods and overwrite itself, without MO2 or its virtual file system. It only reads, and an open load order
never stops MO2 from deleting a mod or renaming a plugin away (ADR 008).

Under MO2, the worker does not need the virtual file system: the host, which runs inside MO2, opens every file
and hands the worker read-only handles. If the worker is not blacklisted, it crashes on start and the run
fails with a message naming the blacklist setting (ADR 002, "MO2").

| Release | Status |
| --- | --- |
| Skyrim Special Edition / Anniversary Edition (`SkyrimSE`) | Tested |

Generated patchers list the targeted releases in `SynthesisMeta.json`.

## Record types

Every Skyrim record type is read: the index and reader agree with Mutagen on every record of the base game and its
Creation Club content (`LoadOrderIndexTests`, and the benchmarks' `check-*` commands). Every type the base game has
(124) can be overridden, and every type but cells, worldspaces and dialog topics has been created, through the
sandbox, the host's validation and the commit (`EveryFormTests`, category `Game`). Containers can be created too, but
a program copying one must not copy its child records with it: they are records of their own.

Links to forms the engine defines itself (IDs below 0x800 in `Skyrim.esm`, such as PlayerRef) count as present.

## Limits

The publisher defaults (`PatchPolicy.PublisherDefault`). A manifest can lower them, never raise them.

| Limit | Default |
| --- | --- |
| Worker memory | 4 GiB (`SandboxOptions.MemoryLimitBytes`); set `SAFEPATCH_WORKER_MEMORY_MB`, or `--worker-memory` for the CLI and MCP server |
| Run time | 10 minutes |
| Records added, changed or removed | 100,000 (manifests default to 10,000) |
| Worker frame | 512 MiB |
| Loose asset requests | 100,000, up to 4 GiB in total |
| Log kept | 200,000 characters |

Measurements behind these numbers are in the implementation plan ("Scale measurements").

## Known limitations

- **Localized text on changed records.** When the real output is localized, a record SafePatch changed carries
  text in the target language only (ADR 006, "Findings").
- **Very large cells.** Changing tens of thousands of references inside a single cell is quadratic in Mutagen,
  and the host pays that cost twice more than a native patcher would (implementation plan, "Scale measurements").
- **Game INI.** Archives listed in the main game INI (`Skyrim.ini`) are visible to `state.AssetProvider`, as in
  Synthesis. Other INI files are not read, also as in Synthesis.
